Projects

A selection of what I've built — ranging from accessibility-first web apps to full-stack course projects.

🎙️
SoundBite — Voice-First Food Delivery
Featured

The world's first food ordering platform designed for visually impaired users. Order entirely by voice, navigate with keyboard shortcuts, and receive audio feedback for every action. Built with React, Web Speech API, and full ARIA compliance. Features a voice orb, real-time order tracker, cart management, and an accessibility panel with high-contrast mode and adjustable font sizes.
